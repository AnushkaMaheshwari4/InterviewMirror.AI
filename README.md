# Mirror Interview Pro

PROJECT NAME: InterviewMirror AI

Build a fully functional AI-powered interview coaching web application that analyzes a user's interview performance using webcam, microphone, speech analysis, and AI feedback.

IMPORTANT RULES:

Do NOT use mock data.

Do NOT hardcode scores.

Do NOT display fake analysis.

If a feature is unavailable, show "Feature Not Available".

All scores must be generated from actual user input.
